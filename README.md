# TUMBA NOTES

Локальний менеджер нотаток у стилі Google Keep: швидкі картки, чек-листи, пошук — плюс
ієрархічні папки, яких Keep не має. Усе зберігається на пристрої (Room/SQLite), без мережі,
акаунтів і телеметрії.

## Запуск

**Потрібно:** Android Studio (Ladybug або новіша).

1. Відкрийте теку проєкту в Android Studio.
2. Дочекайтеся Gradle sync і запустіть на емуляторі або пристрої.

Жодних ключів, `.env` чи `google-services.json` не потрібно: застосунок повністю офлайн
(мережеві та AI-залежності прибрані зі складу).

Для збірки під Google Play: `app/build.gradle.kts` уже містить `signingConfig` для релізу,
який бере `my-upload-key.jks` з кореня проєкту (або шлях зі змінної `KEYSTORE_PATH`).

## Що вміє

- **Нотатки** — картки з кольором, шпилькою, обраним, архівом і кошиком; сітка або список.
- **Папки** — довільна вкладеність, перенос нотатки між папками, кольори та іконки.
- **Редактор** — WYSIWYG: заголовки, жирний/курсив/закреслений, чек-листи, списки, цитати,
  код, розділювачі, внутрішні посилання `[[Назва нотатки]]`.
- **Пошук** — миттєвий по заголовку й тексту з історією запитів.
- **Резервні копії** — повний JSON-експорт/імпорт (нотатки, папки, теги, шаблони, історія).

## Архітектура

```
app/src/main/java/com/example/
├── data/local/        Room: entities, DAO, database + migrations, seed
├── data/model/        доменні моделі та BackupData
├── data/repository/   TumbaRepository — єдина точка запису
├── ui/viewmodel/      TumbaViewModel — стан і команди UI
├── ui/screens/        Compose-екрани
├── ui/components/     навігація, WYSIWYG-редактор
├── ui/theme/          кольори, типографіка, рядки uk/ru/en
└── utils/             конвертер розмітки, форматування, кольори нотаток
```

Дані зберігаються в `tumba_notes.db` (версія схеми 3). Для оновлення схеми додавайте
`Migration` у `TumbaDatabase` і збільшуйте `version`, інакше Room впаде на перевірці схеми.
