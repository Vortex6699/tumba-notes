# TUMBA NOTES

**TUMBA NOTES — твої думки, ідеї та плани в одному місці.**

Локальний менеджер нотаток для Android, натхненний простотою Google Keep, але з більшими можливостями. Швидкі нотатки, чек-листи, розумний пошук та повноцінна система вкладених папок — усе в одному застосунку.

## Особливості

- 📝 **Нотатки** — кольорові картки, закріплення, обране, архів і кошик.
- 📁 **Вкладені папки** — створюй власну структуру та організовуй інформацію без обмежень.
- ✍️ **Потужний редактор** — форматування тексту, заголовки, списки, чек-листи, цитати та блоки коду.
- 🔗 **Внутрішні посилання** — пов'язуй нотатки між собою.
- 🔎 **Швидкий пошук** — знаходь потрібну інформацію за заголовком або вмістом.
- 💾 **Резервне копіювання** — експортуй та відновлюй свої дані через JSON.
- 🎨 **Персоналізація** — кольори нотаток, іконки папок та різні режими відображення.

## Приватність передусім

TUMBA NOTES працює повністю офлайн.

- Без реєстрації та акаунтів.
- Без підключення до інтернету.
- Без реклами та телеметрії.
- Усі дані зберігаються локально на пристрої за допомогою Room / SQLite.

**Твої нотатки належать тільки тобі.**

## 📥 Встановлення APK

Хочеш спробувати TUMBA NOTES на своєму Android-пристрої?

1. Перейди до розділу **Releases** цього репозиторію.
2. Завантаж останню версію файлу `TUMBA-NOTES.apk`.
3. Відкрий завантажений APK на своєму пристрої.
4. Підтвердь встановлення, якщо Android попросить дозвіл.

**Важливо:** завантажуй APK лише з офіційного репозиторію TUMBA.

[⬇️ Завантажити останню версію](../../releases/latest)

**Платформа:** Android
## Запуск проєкту

1. Завантаж репозиторій.
2. Відкрий проєкт в Android Studio (Ladybug або новішій).
3. Дочекайся завершення Gradle Sync.
4. Запусти застосунок на Android-пристрої або емуляторі.

Додаткові API-ключі, `.env` та `google-services.json` не потрібні.
